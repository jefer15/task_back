# Task Management API

This is a simple **Task Management API** built with **.NET 8** and **ASP.NET Core**. It allows users to create, update, delete, and retrieve tasks using an **in-memory storage** approach (no database required).

## Getting Started

### Prerequisites
Ensure you have the following installed:
- **.NET 8 SDK** 

### 🛠 Installation & Running Locally
1. **Clone the repository** (Ensure you are on the `develop` branch):
   ```sh
   git clone -b develop https://github.com/jefer15/task_back.git
   cd task-back
   ```
2. **Restore dependencies**:
   ```sh
   dotnet restore
   ```
3. **Run the application**:
   ```sh
   dotnet run
   ```
4. The API will be available at:
   ```
   http://localhost:5223
   ```
